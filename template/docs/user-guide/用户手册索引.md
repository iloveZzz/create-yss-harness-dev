# 使用手册

本文档面向使用本模板初始化项目的开发者、产品/架构协作者和 AI Agent 操作者。

## 当前范围

本模板提供文档骨架、契约模板、项目级 Agent skills 和协作约定。

## 推荐流程

`template-source` 只维护模板，不生成具体产品资产。`project-instance` 的默认链路：

```text
harness-entry → tactical-design → slice-contract → slice-implementation → verification
```

1. 读取当前仓库根 `yss-project.yaml`、`AGENTS.md` 与 `CONTEXT.md`；不要混用父目录或其他 submodule 的入口文件。
2. 批准的上游 Spec / 战略设计、原型和 OpenAPI 进入 `harness-entry`。
3. 领域影响由 `architecture-agent` 使用 `yss-tactical-design` 形成战术设计合同。
4. Harness Orchestrator 批准统一 Slice Implementation Contract 后，前端 / 后端 / 测试按同一合同实现。
5. 测试 Agent 独立执行 Fresh Verification。`grill-with-docs`、`to-spec`、`to-tickets` 只作为显式兼容入口。
