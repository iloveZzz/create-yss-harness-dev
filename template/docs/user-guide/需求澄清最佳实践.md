# 需求澄清最佳实践

本旧入口保留用于兼容链接。当前仓库职责为：消费批准 Spec/战略输入，统一组织架构、前后端和测试；不以 Discovery 为默认入口。可继续服务既有通用项目，不要求迁移专职 profile。

推荐先读 [通用研发指南](研发子项目用户手册.md)，协作和反模式见 [本仓最佳实践](生命周期最佳实践.md)，完整练习见 [设备借用案例](设备借用贯穿案例.md)。原全栈/全生命周期重复步骤已合并，不能用旧章节绕过当前 profile。

澄清时把业务决定、技术事实、待验证假设分开；只有有权用户确认业务变化，Agent 负责核对环境事实。下游发现上游规则含糊时回交，不能默认为新规则。
